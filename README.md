# 포트리스 4인 대전 (HTML5 + Google Apps Script)

추억의 턴제 포격 게임 **포트리스** 스타일을 HTML5 Canvas로 새로 만든 게임입니다.
서버는 **Google Apps Script(GAS)** 웹앱이라, 별도 서버 없이 구글 계정만 있으면 **최대 4명이 온라인으로** 같이 할 수 있습니다.

> 캐릭터, 이름, 그림은 모두 새로 디자인했습니다(원작 에셋 미사용).

## 주요 기능

| 구분 | 내용 |
|---|---|
| 탱크 6종 | 캐논 · 미사일 · 레이저 · 멀티 · 아이스 · 에어 (각각 1번/2번 무기 + **SS 필살기**) |
| 캐릭터 디테일 | 해치에서 고개를 내민 조종사(헬멧=플레이어 색, 고글, 눈 깜빡임, 피격 시 `>_<` 표정, 체력 낮으면 식은땀), 굴러가는 무한궤도·바퀴, 펄럭이는 깃발, 반동, 회전하는 레이더/접시 안테나/개틀링/프로펠러, 저체력 연기, 파괴 시 잔해 |
| 무기 | 산탄, 연발 미사일, 유도 미사일, 바람 무시 플라즈마, 지형 관통 드릴, 공중 분열탄, 바운스탄, 빙결(딜레이 증가), 빙벽 생성, 위성 레이저, 폭격기 호출, 고드름 비 |
| 맵 5종 | 초원 · 사막 · 설원 · 달밤(오로라) · 화산(용암) — 매번 랜덤 생성, 공중 섬·지하 동굴, **픽셀 단위 지형 파괴** |
| 규칙 | 매 턴 바뀌는 바람, 이동 게이지, 25초 제한, **딜레이 턴제**(강한 무기·많은 이동 = 늦은 차례), 추락/낙하 데미지, SS 게이지 |
| 모드 | 로컬 대전(한 PC 2~4명, CPU 추가 가능) / 온라인 대전(방 코드 4자리, 최대 4명, 방장이 CPU 추가 가능), 개인전·팀전 |
| 기타 | WebAudio 합성 효과음(외부 파일 없음), 모바일 터치 조작, 타이틀 화면의 CPU 데모 대전 |

## 조작법

| 키 | 동작 |
|---|---|
| `←` `→` | 이동 (MOVE 게이지 소모) |
| `↑` `↓` | 포신 각도 (길게 누르면 빨라짐) |
| `Space` 누르고 떼기 | 파워 충전 → 떼는 순간 발사 (파워 게이지의 노란 표시 = 지난 파워) |
| `1` `2` `3` | 무기 선택 (3 = SS, 게이지 100%일 때) |
| `Tab` | 턴 넘기기 |

모바일에서는 화면의 ◀ ▶ ▲ ▼ / 발사 버튼을 사용합니다.

## 바로 해보기 (설치 없이, 로컬 대전)

`dist/fortress.html` 파일을 브라우저로 열면 됩니다. 온라인 대전만 GAS 배포가 필요합니다.

## Google Apps Script로 배포 (온라인 4인 대전)

### 방법 A — 복사/붙여넣기
1. <https://script.google.com> → **새 프로젝트**
2. 기본 `Code.gs` 내용을 `src/Code.gs` 로 교체
3. **파일 추가 → HTML** 로 아래 6개를 만들고 각각 같은 이름의 `src/*.html` 내용을 붙여넣기 (확장자 없이 이름만)
   `Index`, `Styles`, `Core`, `Sim`, `Render`, `Game`
4. (선택) 프로젝트 설정 → "appsscript.json 표시" 후 `src/appsscript.json` 내용으로 교체
5. **배포 → 새 배포 → 유형: 웹 앱**
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한: **모든 사용자** (또는 "Google 계정이 있는 모든 사용자")
6. 나온 웹앱 URL을 친구들에게 공유 → 한 명이 **방 만들기**, 나머지는 **4자리 코드로 참가**

### 방법 B — clasp
```bash
npm i -g @google/clasp
clasp login
clasp create --type webapp --title "포트리스 4인 대전" --rootDir src
clasp push
clasp deploy
```

## 4인 온라인은 어떻게 동작하나요?

GAS는 웹소켓이 없어서 **폴링(약 0.8초 간격) + 결정적 시뮬레이션** 방식을 씁니다.
턴제 게임이라 이 방식으로 충분히 자연스럽습니다.

```
[쏜 사람 브라우저]  발사 → 물리 시뮬레이션을 즉시 끝까지 계산(지형 파괴 목록, 체력, 위치)
        │                → 서버에 {발사 파라미터 + 결과} 전송 & 바로 애니메이션 재생
        ▼
[Code.gs 서버]  턴 검증 → 이벤트 로그에 기록 → 딜레이로 다음 턴/바람 결정, 승패 판정
        ▼
[다른 브라우저]  폴링으로 이벤트 수신 → 같은 파라미터로 똑같이 재생 → 결과로 최종 보정
```

- 서버가 **턴 순서·바람·승패**의 최종 권한을 갖고, 물리 결과는 쏜 사람이 계산합니다.
- 이동/조준은 실시간(약 0.35초 간격)으로 공유되어 상대가 움직이는 모습도 보입니다.
- 응답 없는 플레이어는 15초 후 턴이 넘어가고, 90초 이상 끊기면 탈주 처리됩니다.
- CPU는 방장 브라우저가 대신 조종합니다.
- 저장소는 `CacheService`(최대 6시간)라 별도 시트/DB 설정이 필요 없습니다.

**GAS 한도 참고**: 무료 계정 기준 동시 실행 30개, 일일 URL Fetch/실행 시간 한도가 있습니다. 4명이 0.8초마다 폴링해도 동시 실행은 4~8개 수준이라 소규모 친구 대전에는 문제없습니다. 여러 방을 동시에 많이 돌리면 한도에 걸릴 수 있습니다.

## 프로젝트 구조

```
src/
  Code.gs          GAS 서버: 방/로비, 턴·딜레이·바람·승패, 이벤트 로그, 폴링
  appsscript.json  웹앱 설정
  Index.html       화면 뼈대 (include 로 아래 파일 삽입)
  Styles.html      UI 스타일 (로비, HUD, 반응형)
  Core.html        상수, 탱크/무기 데이터, 맵 테마, 효과음 합성
  Sim.html         지형 생성·파괴, 포탄/탱크 물리 (결정적 시뮬레이션)
  Render.html      지형/배경 그리기, 탱크 캐릭터 아트, 포탄, 파티클 이펙트
  Game.html        게임 진행, 입력, CPU AI, HUD, 로컬/온라인 백엔드
tools/
  build.js         src → dist/fortress.html (단일 파일) 빌드
  gas-mock.js      Code.gs 를 Node 에서 돌리는 목(mock)
  test-online.js   브라우저 3개 + CPU 1명 온라인 대전 동기화 테스트
  smoke.js         로컬 대전 스모크 테스트
dist/fortress.html 빌드 결과 (바로 열어서 플레이)
```

## 개발

```bash
node tools/build.js                          # dist/fortress.html 재생성
NODE_PATH=$(npm root -g) node tools/smoke.js # Playwright 필요
NODE_PATH=$(npm root -g) node tools/test-online.js
```

`test-online.js` 는 `Code.gs` 를 목 서버로 띄우고 브라우저 3개(사람) + CPU 1명으로 실제 대전을 진행하면서,
매 턴마다 모든 클라이언트의 **지형 파괴 목록·체력·위치가 동일한지** 검사합니다.
